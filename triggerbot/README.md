# TriggerBot (Fabric 1.21.8)
Requires: Java 21, Fabric Loader, Fabric API, Cloth Config, Mod Menu.
Build: install Gradle 8.14+, then run `gradle build` (or `gradle wrapper` first, then `./gradlew build`).
Jar: build/libs/triggerbot-1.0.0.jar
Keybind: Options -> Controls -> Key Binds -> TriggerBot (default R, rebind to any key).
Settings: Mod Menu -> TriggerBot. Config file: config/triggerbot.json
